# Motor de decisión v1.4 · principios de control

El motor está diseñado para reducir decisiones, no información.

## Guardrails

- **Veto antes que afinidad:** un incumplimiento conocido de beneficiario, territorio, población o plazo no puede compensarse con coincidencias temáticas.
- **Obligación antes que conveniencia:** una obligación no baja porque sea cara o compleja; cambia la vía recomendada.
- **Reutilizar antes de comprar:** servicio común o provincial verificado se muestra antes de una contratación equivalente.
- **No confundir derecho con prestación real:** “la Diputación puede/debe asistir” no se presenta como “este servicio existe” salvo fuente provincial verificada.
- **EATIM conservadora:** no se presumen competencias municipales; umbral administrativo y escala local se separan.
- **Financiación como acelerador:** una ayuda no convierte en prioritario un proyecto que no responde a necesidad o cumplimiento.
- **Sin falsa precisión:** scores internos sirven para ordenar y probar, nunca se muestran como 0–100.
- **Datos ausentes no son ceros:** si falta una variable, el motor reduce confianza o deja una comprobación, pero no inventa el dato.
- **Diversidad:** las primeras recomendaciones no pueden concentrarse excesivamente en una sola categoría/familia.

## Capas de contexto utilizadas cuando existen

- tipo de entidad;
- municipio matriz;
- población administrativa y local;
- variación demográfica;
- densidad;
- edad y población mayor/joven;
- hogares unipersonales;
- renta relativa a municipios similares;
- conectividad;
- servicios comunes;
- apoyo provincial verificado;
- funciones provinciales previstas legalmente;
- obligaciones y controles prioritarios;
- complejidad/coste/mantenimiento del proyecto;
- financiación y plazos;
- calidad de la evidencia.
