Qué sabemos, de qué año es y de dónde sale

Brújula no mezcla años ni rellena huecos. Cada indicador mantiene referencia, unidad, organismo y enlace oficial.

Diccionario de indicadores

Los datos territoriales cambian mucho menos que BDNS o BOE: se actualizan con cadencia anual/semestral para no malgastar recursos gratuitos.

Sin falsa precisión

Brújula no calcula una nota única de “salud municipal”. Una baja densidad puede ser una restricción para un servicio y una ventaja para otro. Por eso conserva dimensiones separadas y explica la regla aplicada.
